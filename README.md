# Arter

A modern desktop app that turns any image into ASCII art.

## Features

- Dark, rounded, modern UI
- Custom title bar (no system chrome)
- Live image preview
- Adjustable width, character ramp, contrast, invert
- Export to `.txt`, `.html`, `.md`
- Single-file `.exe` — no Python required for end users

## Run from source

```bash
pip install -r requirements.txt
python arter.py
